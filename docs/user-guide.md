# 재활 연구 통계 길잡이 사용 안내

재활 연구를 처음 시작하는 사람이 연구 설계에 맞는 통계 방법을 찾고, 자신의 데이터로 분석을 확인할 수 있도록 만든 도구입니다.

- 별도 설치나 로그인 없이 사용할 수 있습니다.
- 업로드한 파일은 사용 중인 브라우저 안에서만 처리되며 서버로 전송되지 않습니다.
- 추천 결과는 학습과 분석 선택을 돕는 자료입니다. 최종 연구 설계와 해석은 지도자 또는 통계 전문가와 확인하세요.

사이트: <https://suah7475.github.io/2.0_auto_statistical_method/>

## 빠른 시작

1. 통계 방법을 모르면 **질문으로 추천받기**를 선택합니다.
2. 내 연구에 맞는 답을 차례로 고릅니다. 필요한 질문만 나타납니다.
3. 추천 분석의 쉬운 설명과 재활 예시를 먼저 확인합니다.
4. **파일로 바로 분석** 또는 **R 코드 만들기**를 선택합니다.
5. 결과에서 본분석, 효과크기, 가정 검정, 결측치 안내를 함께 확인합니다.

분석 방법을 이미 알고 있다면 첫 화면에서 **통계 방법 직접 선택**을 사용할 수 있습니다.

## 질문 고르기

### 1. 결과 변수

연구에서 가장 알고 싶은 결과를 뜻합니다.

| 종류 | 예시 |
|---|---|
| 숫자로 측정한 결과 | 통증 점수, 보행 속도, 관절가동범위, 악력 |
| 그룹이나 종류로 나눈 결과 | 치료 성공/실패, 정상/비정상, 경증/중등증/중증 |

### 2. 원인 또는 조건 변수

결과를 비교하거나 설명할 때 함께 보는 변수입니다.

| 종류 | 예시 |
|---|---|
| 그룹 변수 | 실험군/대조군, 치료 A/B, 성별 |
| 숫자 변수 | 나이, 치료 횟수, 발병 기간 |

변수가 1개이면 한 종류만 고릅니다. 변수가 2개 이상이고 두 종류가 섞여 있다면 둘 다 선택합니다.

### 3. 관계와 예측

결과 변수와 원인 변수가 모두 숫자이고 변수가 1개일 때만 나타납니다.

- **두 값의 관계 확인**: 치료 횟수와 회복 점수가 함께 변하는지 알고 싶을 때
- **한 값으로 결과 예측**: 치료 횟수로 예상 회복 점수를 계산하고 싶을 때

### 4. 같은 사람을 반복 측정했는지

- 서로 다른 사람 비교: 실험군 20명과 대조군 20명
- 같은 사람 반복 측정: 환자 20명의 치료 전과 치료 후

### 5. 정규분포인지

확인하지 못했다면 **아니오 / 잘 모름**을 선택합니다. 이 경우 도구는 Spearman 상관분석이나 비모수 검정처럼 분포 가정이 적은 방법을 우선 제안합니다.

질문은 최대 9종류가 준비되어 있지만 답에 필요한 항목만 나타나므로, 일반적인 연구에서는 더 적은 단계로 끝납니다.

## 데이터 파일 준비

브라우저 분석은 Excel `.xlsx`와 CSV `.csv` 파일을 지원하며 최대 크기는 10MB입니다.

### 공통 원칙

1. 첫 번째 행에는 서로 다른 열 이름을 넣습니다.
2. 한 행에는 한 대상자 또는 한 번의 측정만 넣습니다.
3. 숫자 열에는 단위 글자를 섞지 않습니다. `25kg` 대신 `25`를 입력합니다.
4. 없는 값은 빈 칸으로 두거나 `NA`로 입력합니다.
5. 셀 병합, 제목 행, 중간 합계 행은 제거합니다.

### 독립된 두 그룹 예시

| 환자ID | 치료군 | 치료후_점수 |
|---|---|---:|
| P01 | 실험군 | 72 |
| P02 | 대조군 | 61 |

### 같은 사람의 전후 비교 예시

| 환자ID | 치료전_점수 | 치료후_점수 |
|---|---:|---:|
| P01 | 45 | 62 |
| P02 | 51 | 68 |

### 여러 시점 반복측정 예시

| 환자ID | 시점 | 치료군 | 점수 |
|---|---|---|---:|
| P01 | 치료전 | 실험군 | 45 |
| P01 | 치료후 | 실험군 | 62 |

반복측정 분석에서는 모든 대상자에게 같은 시점이 있어야 하며, 같은 대상자와 같은 시점이 중복되면 안 됩니다.

## 파일로 바로 분석

1. 추천 결과에서 **파일로 바로 분석**을 선택합니다.
2. Excel 또는 CSV 파일을 올립니다.
3. 미리보기에서 행과 열이 올바른지 확인합니다.
4. 분석 역할마다 사용할 열을 연결합니다.
5. 자동 감지된 유형이 틀리면 숫자, 그룹, 순서형 중 맞는 것으로 바꿉니다.
6. **분석 실행**을 누릅니다.

분석 전에 다음 내용을 자동으로 확인합니다.

- 필수 열 선택 여부와 같은 열의 중복 선택
- 숫자 열에 문자가 섞였는지
- 두 그룹 검정에 실제로 그룹이 두 개인지
- 반복측정 자료의 누락 시점과 중복 시점
- 결측치를 제외한 분석 가능 행 수
- 로지스틱 회귀의 사건 범주, 기준 범주, 순서형 범주의 순서

문제가 있으면 분석을 시작하지 않고 고칠 내용을 한꺼번에 보여줍니다.

첫 실행은 R 분석 환경과 패키지를 준비하므로 네트워크 상태에 따라 약 1~3분 걸릴 수 있습니다. 같은 브라우저에서 다시 실행하면 더 빨라질 수 있습니다.

## R 코드 만들기

RStudio에서 직접 분석하려면 **R 코드 만들기**를 선택합니다.

1. 파일 경로와 형식을 입력합니다.
2. 첫 행의 열 이름을 붙여넣고 **열 이름 확인**을 누릅니다.
3. 각 열의 유형을 확인합니다.
4. 분석 역할에 맞는 열을 연결합니다.
5. 생성된 코드를 복사하거나 `.R` 파일로 내려받습니다.

생성 코드에는 데이터 읽기, 전처리, 기술통계, 가정 검정, 본분석, 효과크기, 그래프, 해석 안내와 Excel 결과 내보내기가 포함됩니다.

## 결과 읽기

결과는 다음 순서로 확인하는 것이 좋습니다.

1. **분석 대상 수**: 결측치를 제외하고 몇 행이 사용되었는지 확인합니다.
2. **기술통계**: 평균, 표준편차, 중앙값과 그룹별 분포를 확인합니다.
3. **본분석 결과**: p값과 신뢰구간을 확인합니다.
4. **효과크기**: 차이가 얼마나 큰지 확인합니다.
5. **가정 검정과 그래프**: 분석 방법의 조건이 맞는지 확인합니다.

`p < 0.05`만으로 임상적으로 중요한 결과라고 결론 내릴 수 없습니다. 효과크기, 95% 신뢰구간, 표본 수와 재활 현장에서의 의미를 함께 해석하세요.

## 관련 논문 찾기

추천 결과 아래에서 재활 분야를 선택해 PubMed 논문을 찾을 수 있습니다. **주요 재활·의학 저널만**을 켜면 도구에 등록된 주요 저널 목록으로 결과를 좁힙니다. 이 표시는 개별 저널의 현재 등재 상태를 보증하지 않습니다.

## 문제 해결

- **한국어가 깨져 보여요**: CSV를 UTF-8 또는 EUC-KR로 저장하거나 `.xlsx` 파일을 사용합니다.
- **숫자 열이 그룹으로 감지돼요**: 열 옆 유형 선택에서 **숫자**로 바꿉니다.
- **분석 실행이 시작되지 않아요**: 빨간 안내 상자에서 빠진 열, 그룹 개수, 결측치 문제를 확인합니다.
- **첫 실행이 오래 걸려요**: R 패키지를 내려받는 중일 수 있습니다. 네트워크를 확인하고 1~3분 기다립니다.
- **일부 단계에 오류가 보여요**: 성공한 결과도 함께 표시됩니다. 오류 단계의 데이터 조건을 확인하거나 R 코드를 내려받아 RStudio에서 실행합니다.

## 지원 환경과 한계

최신 Chrome 또는 Edge 사용을 권장합니다. 이 도구는 통계 자문, 표본 수 산정, 연구 설계 검토를 대신하지 않으며 업로드한 데이터의 임상적 타당성을 자동으로 판단하지 않습니다.
